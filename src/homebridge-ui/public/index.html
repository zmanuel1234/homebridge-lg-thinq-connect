Signing in to LG
  1. On a computer, open connect-pat.lgthinq.com and choose your country at the top first: it decides which LG sign-in you get. Use the same country as in the Country setting below.
  2. Sign in with the same LG account the ThinQ app shows your appliances on. If you signed up in the app with Google, Apple or Facebook, or aren't sure which account it is, choose sign in with QR code and scan it with the phone that has the ThinQ app.
  3. Choose ADD NEW TOKEN, name it (for example Homebridge), tick every permission under Scope of authority, then choose CREATE TOKEN.
  4. Copy the token, paste it in the Token box below, set your Country, then press Check token.

The token works until you delete it on that page. Keep it private: it's only stored in this Homebridge's settings. Checking it here doesn't save anything; press Save when you're done.
